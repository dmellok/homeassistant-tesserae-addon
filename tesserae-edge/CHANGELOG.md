# Changelog

## 0.464.0-edge.1792272017, 2026-10-17

[`de7b9bd`](https://github.com/dmellok/tesserae/commit/de7b9bda546e755d23f06e9476593e4b67fc80ac) feat(settings): Generative AI, one page for every widget that paints. The fal.ai key they share (a widget's own still comes first) with a Check that asks fal.ai without painting, two ceilings over all of them together in US dollars a day and a month, and the ledger every charge is written to: to-day, the month, the last thirty days, who is painting with a link to its pictures, and the month by widget and model. A send waits for the page's paintings: a push of a page with a widget that asks to be run ahead runs the page first and, while it still asks for a refresh, again after that wait, up to five minutes, so the panel paints the finished page once; follow-ups and warms never wait; History says how long. The tesserae_min gate reads the checkout's pyproject before the installed package's metadata, which went stale on a source install and turned current widgets away. Bump to 0.464.0
